# Sistema Acadêmico — Análise e Garantia da Qualidade de Requisitos

## Sobre o projeto

Este repositório foi desenvolvido para a Lista de Exercícios III da disciplina de Gestão e Qualidade de Software.

O projeto apresenta o levantamento, a análise e a garantia da qualidade dos requisitos de um Sistema Acadêmico, contemplando requisitos funcionais e não funcionais, modelagem de dados, arquitetura, estratégia de versionamento e plano de testes.

## Sistema desenvolvido

O Sistema Acadêmico tem como objetivo auxiliar no gerenciamento das principais informações acadêmicas de uma instituição de ensino, incluindo:

- cadastro de alunos;
- cadastro de professores;
- cadastro de disciplinas;
- gerenciamento de turmas;
- matrícula de alunos;
- lançamento e consulta de notas;
- emissão de histórico acadêmico.

## Documentação

A documentação do projeto contém:

- visão geral e escopo do sistema;
- requisitos funcionais (RF);
- requisitos não funcionais (RNF);
- critérios de aceite;
- Diagrama Entidade-Relacionamento (DER);
- Diagrama de Classes;
- estratégia de versionamento;
- política de Pull Requests e Code Review;
- Plano de Garantia de Qualidade (QA);
- cenários de teste.
